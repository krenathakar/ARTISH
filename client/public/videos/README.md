# Artish UK — Hero Video Assets Directory

Place your original authorized video assets in this directory for the homepage hero background video.

## Required Asset Filenames

1. **Desktop Hero Video** (Preferred 16:9, 1920×1080 or 1280×720 MP4, H.264 video codec):
   `hero-artish.mp4`

2. **Mobile Hero Video** (Preferred 9:16, 1080×1920 MP4, H.264 video codec):
   `hero-artish-mobile.mp4`
   *(If not supplied, the website gracefully falls back to `hero-artish.mp4`)*

3. **Poster Fallback Image** (WebP or JPG frame of the video):
   `hero-artish-poster.webp`

## Instagram Reel Reference
Reference content source: https://www.instagram.com/reel/DWLr2APKmoT/

## Video Compression Recommendations for Web
- **Codec**: H.264 / AAC
- **Container**: MP4
- **Bitrate**: ~2.5 - 4.5 Mbps for Desktop, ~1.5 - 2.5 Mbps for Mobile
- **Frame Rate**: 24 or 30 fps
- **Muted**: Video will play muted as a background showreel.
